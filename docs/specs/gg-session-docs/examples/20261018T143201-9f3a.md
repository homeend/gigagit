Scroll events are coalesced per frame so a burst of wheel ticks costs one layout.

## How it works
1. [The wheel handler](internal/tui/scroll.go:8-12) adds the tick's delta under the lock.
2. [flush](internal/tui/scroll.go:14-21) runs once per tick and applies the sum.
3. [Why one lock](note:20261018T143205-c0d1) — the handler and the tick both reach the field.
