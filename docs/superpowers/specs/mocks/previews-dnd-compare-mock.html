    Drag & drop compare — what to try

    1. Drag login, attempt A onto login, attempt B. While you hover, the target row is outlined (the branch list's highlight). Release → a small menu: both directions, and compare and save….

    2. Hover the row you are dragging, or the comparison row at the bottom: no outline, the browser's “no drop” cursor. Releasing does nothing.

    3. Drag the broken row (missing: agent-x) — allowed; the server's refusal appears on the op line at the bottom.

    4. No mouse drag? Right-click a preview or pair row → compare with… opens the existing dialog with the left link filled in.

    After a compare, the header shows the kind badge and (two sets, wide window, ⇄ on) the symmetric view. x / the arrow flips.
