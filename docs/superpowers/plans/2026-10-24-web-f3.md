# gg web F3 Implementation Plan

> Executed inline (superpowers:executing-plans), test-first.

**Goal:** port the TUI's PR hub keys, notification-centre lifecycle + coverage
(incl. the steer switch ask) and the standalone operation log to gg web.

**Spec:** `docs/superpowers/specs/2026-10-24-web-f3-design.md`

## Global Constraints
- Notice ids are the TUI's, permanent: `stale_git_lock`, `commit_graph_recommend`,
  `narrow_fetch_refspec`, `feature_disabled_<id>`, `tool_template_update`,
  `tool_agent_unsupported_<hash12>`, `steer_switch`.
- Labels: "Not now (ask again next load)", "Never for this repo".
- Session state server-side, in memory, keyed by git common dir; never browser storage.
- Every new key in the `?` help; `go test ./internal/web` after every static edit.
- Mutating routes behind `writeGuard`, bodies under `http.MaxBytesReader`.
- Tests that touch `observ.SetSpanSink` do not `t.Parallel()`.

## Review Focus
1. Two tabs: one opening the centre marks read for both (server-side), a Not now in one hides it in the other.
2. A repo switch with a Not now'd notice: the new repo's notices are unaffected; switching back within the process keeps it hidden (same key).
3. The hub's `/` field and the send panel / verdict prompt stacked over the overlay: their keys never reach the hub's onKey.
4. A steer navigate for another worktree while an op runs: refused 409 as today (the op check stays first) — and a background open is not parked.
5. Op log toggled off while a span is being written — `SetSpanSink` serialises; no double close.

### Task 1: standalone operation log
Files: `internal/web/oplog.go` (new), `serve.go`, `settings.go`, `oplog_test.go`.
- `type webOpLog struct{ mu sync.Mutex; on bool }`, `(l *webOpLog) enable(path string) error`, `disable()`; Server field `opLog *webOpLog` only when standalone (`!s.hosted`).
- Tests: `TestOpLogStandaloneFromConfig` (config on → a span emitted after Serve-equivalent setup lands in the file with the marker), `TestOpLogToggleLive` (PUT op_log false → sink nil; true → writes), `TestOpLogHostedUntouched`.

### Task 2: PR hub keys
Files: `static/prdetails.js`, `static/links.js` (export `copyPRLink(pr)`), `static/prsend.js` (export `verdictBody`), `index.html` (key line), `prdetails_static_test.go`.
- Pure `hubFilter(blocks, q)` (exported, node-tested): blocks `[{heading:bool,text}]` → visible indices with the heading rule.
- Tests: `TestHubFilterJS` (heading kept only with a match, case-insensitive, empty query = all), `TestPRHubKeysWired` (y/L/r/s/v/`/` handled, dynamic imports, recallOpen/recallKey with "filetree", help text names the keys).

### Task 3: centre lifecycle
Files: `notifications.go`, `notice_session.go` (new), `static/notifications.js`, tests.
- `noticeSession{mu; dismissed map[key]map[id]bool; prev map[key]map[id]bool; unread map[key]bool}` on Server.
- `POST /api/notifications/session-dismiss {id}` (any id the current list holds), `POST /api/notifications/read`; GET answers `unread`; every notice gains the two rows (Not now = `session: true`, Never = `dismiss: id`); action click → session dismiss then op.
- Lock error: op end with `domain.IsLockError` → clear `stale_git_lock` session dismissal; done event `lock_error: true`; ops.js appends " — press ! to remove the lock".
- Tests: `TestNoticeSessionDismiss`, `TestNoticeUnreadOnNewID`, `TestNoticeReadClears`, `TestLockErrorClearsSessionDismiss`, `TestNoticeRowsWired` (static).

### Task 4: coverage builders
Files: `notice_locks.go`, `notice_commitgraph.go`, `notemeta_notice.go` → feature-disabled for all, `notice_tools.go`, tests.
- Ops: `remove-stale-locks` (paths from a fresh `RepoHealth.StaleLocks`), `commit-graph-auto` (SetGitConfig fetch.writeCommitGraph=true); action `open: "exttools"` handled client-side by `openExtToolsView`.
- Tests per builder: fires / nil, ids, action list; ops build from server state only.

### Task 5: steer switch ask
Files: `steer_ask.go` (new), `steer.go`, `static/notifications.js`, tests.
- `steerWorktreeBound(c)`; in `handleSteer` after the op-in-flight check and before emit: bound && c.Worktree != "" && !SameCheckout(c.Worktree, shown) → park, reply `steerFail(c, "gg web is showing worktree X; asked the user to switch to Y")`.
- `POST /api/notifications/steer {act: "switch"|"ignore"}` → switch: setStartAt(replay), answer `{worktree}`; client `doReroot(worktree)`. Re-root clears the slot.
- Tests: `TestSteerAskParks`, `TestSteerAskSameWorktreeEmits`, `TestSteerAskSwitchSetsStartAt`, `TestSteerAskIgnore`, notice built.
