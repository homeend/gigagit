# Go to line Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **This repo:** CLAUDE.md forbids implementer subagents — execute with superpowers:executing-plans in the main session; only the final whole-branch review runs as a (read-only) subagent.

**Goal:** `:` → "go to line N" on every window that shows a file's content, in the TUI and in gg web.

**Architecture:** One small TUI prompt type (`lineJump`, a digits-only twin of the in-view `textSearch`) that each host — contentPopup (viewer / View-file preview / split file / split diff), the split's stack pane, blame, diff view (single + stacked), history — owns, checks FIRST while typing, opens on `:`, and resolves with its own landing recipe (all of which already exist for `gg://` links). Diffs answer "is the line shown?" in place, else open the newer version in the viewer when `diffView.newerSide()` can name it, else unfold and land. The web mirrors it with one `gotoline.js` (pure parse + newer-side rule + the shared prompt) wired into viewer.js, files.js/stackview.js, filehist.js.

**Tech Stack:** Go 1.26, Bubble Tea v1, i18n TOML bundles; vanilla ES modules (web), node-run guarded-section tests.

**Spec:** `docs/superpowers/specs/2026-10-23-go-to-line-design.md`

## Global Constraints

- Key is `:` everywhere; `:` is text (never a jump) while a search / filter / prompt is typing or a character selection is on.
- Line numbers 1-based; empty or 0 = cancel; at most 7 digits are accepted (more are ignored).
- Past the end → last line + the EXISTING notice `line %d is past the end of %s (%d lines)` (TUI `i18n.T` key; web `landLine` text).
- Every user-visible TUI string through `i18n.T` with a literal key present in ja/ko/zh/ru (skill `adding-translations`); badge text (`:` + digits + `█`) is punctuation and digits — built WITHOUT i18n, like `textSearch.badge`.
- Every new key in BOTH `?` help (`help.go`; web `registerHelp`/`index.html` rows) and the surface's footer/hint.
- Diff footer: `[f] part` → `[:] line` in BOTH `diffHintFor` lines (same 8 columns; `TestDiffHintFitsTheBudget` stays at exactly 140); update `diffHintFor`'s doc comment with the trade.
- No `internal/git` import from tui; no new deps; tests `t.Parallel()`; TDD.
- Work in `/work/gigagit/.claude/worktrees/go-to-line` (absolute paths; `git -C`).

## Review Focus

1. `:` while `/` search is typing (or `v` char-select is on) → must append to the query / be the mode's, not open the jump — test in Task 2 (viewer) and Task 4 (diff).
2. A doc still loading, empty, binary or too large (placeholder lines, `!p.lines[0].src`) → jump is a no-op, no panic, no cursor move — test in Task 2.
3. Huge / leading-zero numbers (`00012`, `99999999`) → `00012` = 12; digits past 7 ignored; past-end clamps with the notice — Task 1 + Task 2.
4. Diff loading / error / binary / image pair → `:` ignored (no prompt) — Task 4.
5. Stacked diff with the cursor on a header or a collapsed / not-yet-loaded file → the jump targets that file (unfold + park like `landSteer`), never another file carrying the same number — Task 4.
