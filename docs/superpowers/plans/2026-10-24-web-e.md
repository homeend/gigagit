# gg web E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, this session).

**Goal:** port the TUI's worktree claim / reserve marks and rows, and its quit guard, to gg web.

**Architecture:** marks ride `/api/worktrees` (domain `WorktreeMarks`); two small POST handlers write through the domain; the quit guard is a `quitGuard` value in `internal/web` fed by an injected signal channel and `/api/quit`, and the page shows the ask in the ctrl+\ switcher.

**Spec:** docs/superpowers/specs/2026-10-24-web-e-design.md

## Global Constraints

- TUI words verbatim (spec §1, §2). Web is English only.
- Every mutation: `writeGuard` + `http.MaxBytesReader`.
- `go test ./internal/web` after every static edit.
- Kill order on quit: `Tasks().KillAll` then `Sessions().KillAll`, bounded by 5 s.

## Review Focus

- A claim on a worktree that is not in the list (stale page) → 400, nothing written.
- Two tabs open during the ask: cancel in one takes the ask down in both.
- A second Ctrl+C after cancel asks again (not quits).
- Hosted page: `/api/quit` refused; no quit mode ever.
- Quit confirmed twice (page Q + Ctrl+C) → one kill sequence, no panic.

### Task 1: `domain.LiveWork`

- Move the TUI's `liveWork` to `internal/domain/livework.go` as `LiveWork() int`; TUI `quit_guard.go` and `sessions_popup.go` call it.
- Test: `go test ./internal/tui -run Quit` and `./internal/domain` stay green (behaviour move, existing TUI tests pin it).

### Task 2: marks on the wire and in the row

- Test `TestWorktreesCarryMarks` (web): a fixture repo with a linked worktree, a `gg-claim` written with a foreign `host`, and `[agents] reserved = ["<rel>"]` → `/api/worktrees` row has `claim.agent`, `claim.since` (RFC3339), `claim.note`, `reserved: true`; the main row has neither.
- `worktreeRow` gains `Reserved bool json:"reserved,omitempty"` and `Claim *worktreeClaim json:"claim,omitempty"`.
- Static `wtmarks.js` pure fns (node-tested via `jsFunc`): `markPrefix(w)` → `"⚑ bob  ⊘  "`; `claimHint(w, fmt)` → TUI bar text; `markRows(w)` → `[{id:"release", label:"Release claim (bob)"}, {id:"unreserve"|"reserve", label}]`.
- `renderWorktrees` draws `markPrefix` before the label and appends `claimHint` to the title on a new line.

### Task 3: rows + handlers

- Tests: `POST /api/worktree/reserve {path,on}` toggles the config list (on, then off); unknown path → 400; `POST /api/worktree/release-claim {path}` removes the claim file; each fans out `worktrees`.
- sessions.js worktree registration = `startActs(path).concat(markActs(w))`; release asks with `showLocalConfirm("<agent> is working in <dir>. Release its claim?", ["Release","Cancel"])`; `opBusy()` refuses; `opLine` carries the TUI's words. Source pin on the order and on `escapeOption(["Release","Cancel"]) === "Cancel"`.
- Help text in the "starting agents" entry.

### Task 4: server quit guard

- `quit.go`: `type quitGuard` with `asking`, `confirmed`, `live func() int`, `kill func(ctx)`; `run(ctx, sig <-chan os.Signal, closeHost func())` loop; `handleQuitGet` / `handleQuitPost`.
- Tests (injected channel, fake live/kill): no live work → first signal closes; live → asking + `quit` fan-out, second signal → kill then close; cancel POST → asking false, next signal asks again; POST confirm when not asking → 409; hosted → 409; ctx.Done → no ask, kill still runs (safety net); double confirm → one kill.
- `Serve` wires it (production `signal.Notify(ch, os.Interrupt)`), stderr lines from the spec.

### Task 5: page quit mode

- openfiles.js: `quit` live reason → `gg:quit` event → `refreshQuit()` reads `GET /api/quit`; asking → open (or flip in place) the switcher in quit mode: header, tabs agents/tasks, tasks row keys off, foot `Q kill all and quit` / `esc cancel`; not asking → leave quit mode (close if it opened for the ask).
- Pure `quitHeader(n)` and `quitTabs()` node-tested; source pins on Q before tab handlers.
