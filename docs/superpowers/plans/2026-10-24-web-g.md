# gg web G Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, this session).

**Goal:** port the TUI's create-worktree popup (path template, fields, `e`/`E`/`p`/`w`/`W`/`h`/`m`) to gg web.

**Architecture:** domain previews (the TUI's `recompute`); `/api/worktree/preview` serves it; `create-worktree` grows the options and bumps counters after success; `wtnew.js` is the dialog every entrance opens.

**Spec:** docs/superpowers/specs/2026-10-24-web-g-design.md

## Global Constraints

- TUI words verbatim (spec "The TUI"). Web is English only.
- Every POST: `writeGuard` + `http.MaxBytesReader`; wire refs checked against fresh reads.
- Counters bump only after a successful create; names server-derived.
- `go test ./internal/web` after every static edit.

## Review Focus

- A stale preview reply (fast typing) must not overwrite a newer one.
- Seed/now round-trip: the preview shown equals what is created (`<random>`, `<date>`).
- An emptied name on a branch entrance falls back to the selection; an emptied path reverts to the template.
- Create & switch when the op fails or is cancelled at the hook ask: no re-root.
- `path_seq` with a hand-edited path must not be sent (no counter burned).

### Task 1: domain preview

- `internal/domain/newworktree.go`: `type NewWorktreeSpec {Start string; Existing bool; BranchTemplate, PathTemplate, FixedBranch, FixedPath string; Inputs map[string]string; Seed uint64; Now time.Time}`, `type NewWorktreePreview {Labels []string; Branch, Path string; Err error}`, `func (s *Service) PreviewNewWorktree(ctx, NewWorktreeSpec) NewWorktreePreview`, `func WorktreeSeqNames(pathTmpl string) []string`.
- Existing: labels/seqs from the path template only; branch = FixedBranch or Start. Else: both templates; FixedBranch "" → branch template.
- Tests (real repo): existing + `../<repo>.worktrees/<branch>` → path `../<name>.worktrees/b`; `<user:ticket>` labels; non-existing empty fixed → `<parent-branch>-x` template; FixedPath wins; same seed → same `<random>`; `<seq:n>` peeks (no bump).
