# Contributing

gigagit is written and maintained by one person, and it stays that way on
purpose: **this project does not accept pull requests, patches, or code
attached to issues.** A pull request will be closed unmerged, whatever its
quality. This keeps every line of the codebase under a single author, which is
what lets the licensing (see [`LICENSE`](LICENSE) and
[`COMMERCIAL.md`](COMMERCIAL.md)) stay simple.

What is welcome:

- **Bug reports** — a GitHub issue with the `gg` version (`gg version`), the
  platform, what you did, what you expected, and what happened. A repo shape
  that reproduces it (`gg inspect` output, or a `gg --record` keyscript) helps
  most.
- **Feature requests and design feedback** — describe the workflow you want,
  not the implementation.
- **Questions about commercial licensing** — see [`COMMERCIAL.md`](COMMERCIAL.md).

Suggestions are read and may be implemented, but by the author, from the
description, not from submitted code.
